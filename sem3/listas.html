Etiquetas de Lista en HTML5

1. ul — Lista Desordenada

El orden no importa. Viñetas por defecto.

Código que escribes:

<ul>
    <li>Manzana</li>
    <li>Pera</li>
    <li>Plátano</li>
</ul>

Resultado visual:

  • Manzana
  • Pera
  • Plátano

2. ol — Lista Ordenada

El orden sí importa. Números por defecto.

Código que escribes:

<ol>
    <li>Encender el ordenador</li>
    <li>Abrir el navegador</li>
    <li>Escribir la URL</li>
</ol>

Resultado visual:

  1. Encender el ordenador
  2. Abrir el navegador
  3. Escribir la URL

3. li — Elemento de Lista (anidado)

Un li puede contener otra lista dentro.

Código que escribes:

<ol>
    <li>Desayuno
        <ul>
            <li>Café</li>
            <li>Tostada</li>;
        </ul>;
    </li>;
    <li>Almuerzo
        <ul>
            <li>Sopa</li>
            <li>Pollo</li>
        </ul>
    </li>
</ol>

Resultado visual:

  1. Desayuno
    • Café
    • Tostada
  2. Almuerzo
    • Sopa
    • Pollo

4. dl — Lista de Definiciones

Pares de término (dt) + definición (dd).

Código que escribes:

<dl>
    <dt>HTML</dt>
    <dd>Lenguaje de marcado para web.</dd>

    <dt>CSS</dt>
    <dd>Lenguaje de estilos visuales.</dd>

    <dt>JS</dt>
    <dd>Lenguaje de programación.</dd>
</dl>

Resultado visual:

HTML
Lenguaje de marcado para web.
CSS
Lenguaje de estilos visuales.
JS
Lenguaje de programación.

5. menu — Lista de Acciones

Semánticamente para comandos o herramientas. Visualmente igual que ul.

Código que escribes:

<menu>
    <li><button>Copiar</button></li>
    <li><button>Cortar</button></li>
    <li><button>Pegar</button></li>
</menu>

    Resumen de Estructuras

    Etiqueta Estructura mínima Para qué sirve
    ul ul > li Listas sin orden
    ol ol > li Listas con orden numérico
    li Hija de ul, ol, menu Cada ítem de la lista
    dl dl > dt + dd Términos y sus definiciones
    dt Hija de dl La palabra o término
    dd Hija de dl (después de dt) La explicación o definición
    menu menu > li Comandos o acciones interactivas
